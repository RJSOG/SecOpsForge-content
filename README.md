# SecOpsForge : articles

Contenu Markdown du site SecOpsForge. Ce dépôt est séparé du code du site.

- `redteam/`, `blueteam/`, `automation/` : une section du site chacun.
- Les sous-dossiers deviennent des catégories dans la sidebar.
- Le nom du fichier (sans `.md`) est le titre et l'URL de l'article.

Le site lit ce dossier via `NOTES_PATH` (par défaut `./content` à la racine du projet).
